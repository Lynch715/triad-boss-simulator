# 模拟社团老大 · 雾港风云

一款架空港口城市背景的本地生涯策略游戏。玩家接过父亲沈振海留下的“和联胜”，从一条老街起步，招募头目、经营地盘、决定血拼战术、收编敌将，最终统一雾港。

## 已实现

- 60个月主战役，每月3个行动点；发起血拼额外消耗1个行动点
- 人手分能战／整补／养伤三态：出战即离池，整补约2个月归队，养伤4~5个月且要付药钱
- 人手上限绑定地盘数——想养更多人，只能先拿地
- **14块城区**：玩家开局只有老街（全图最小势力），周边3块散户地是早期缓冲区，
  三家社团各3块高驻防地盘，中央港区终局
- 敌方会主动扩张：三家吃散户、互相吞并（第10个月起每月最多两家行动），
  抢到中央港区的一家将与所有人接壤；开局6个月内三家不碰散户——这是玩家抢地的窗口期
- **每月月报**：结束本月先看一屏盘点——账面收支、人手回流、三家动向、账房警讯
- 新打下的地盘有3个月驻防期：收入减半、易被反夺，可派头目坐镇提前结束
- 招募市场：固定剧情角色＋可重玩的普通人才
- 头目五维：武力、统御、谋略、经营、魅力
- 血拼前选地盘、三名头目、参战人手与战术
- 开局、僵持、决胜三段战报，包含伤亡、受伤与俘虏收编
- 地盘经营、驻防、每月收支和敌对势力反攻
- 14名核心人物，角色忠诚、怨气、功劳与伤势持续记录
- 父亲旧账、旧部要位、敌将投降、功高震主等剧情链
- 义、威、利三种执掌倾向与多结局评价
- 本地自动存档，无后端、无CDN、无数据上传

## 可玩性扩展（2026-08）

- **战术克制环**：每块敌方地盘有防守姿态（铁壁死守／外线游斗／重赏死士／人心浮动），查明情报才可见；四种战术各有克制与被克，稳扎稳打对所有姿态中立。蒙着打时战前评估不含姿态修正——情报从加分项变成选战术的依据
- **外部压力有牙齿**：压力顶到75触发警队大扫荡；民心太低触发码头罢工；港城联盟成形后每6个月上门收“公摊”
- **外交层**：递茶讲数（花钱换4个月停战）、挑拨离间（把一家的刀口引向同行）、安插内应（削驻防＋查敌情）
- **头目主政**：可委任头目坐镇地盘，按经营／统御／魅力／谋略持续抬收入、厚驻防、安街面、压风声，但主政期间不能出战
- **事件池扩容与事件链**：走私船、记者调查、父亲旧友、阿七独当一面等选择会在数月后回响
- **章节转折**：第12／24／36／48月各有一次全局抉择，给60个月一个“幕”的结构
- **每局随机世道**：开局抽2条世界规则（阴雨连绵／海关大检查／金价飞涨／老兵还乡／严打之年／走私旺季），可在开局界面换年景
- **流派拉大**：义＝劝降收编流（伤员好得快、收编忠诚高），威＝速攻震慑流（胜仗削邻地驻防），利＝经济流（收入高、讲数和招人便宜）
- **雾港名录（排行榜）**：一统雾港的战役按用时排座次，用时越短名次越前，同用时先比难度；主菜单与结局页可查看。与存档分开存放，删档重开不清榜

## 破局机制（2026-08）

后期的地图会冻住：敌方驻防上限随地盘数一路涨过玩家的攻击天花板（七块地 300 对天花板约 250），
而攻城失败只削几点驻防、下月就长回来——消耗战不成立，钱堆到几千万没处花，双方谁也吃不掉谁。
实测稳健画像 5/24 局跑到 120 个月仍未终结。四组机制治的是这个结构，不是斜率：

- **围困消耗战**：对一块敌方地盘打过一场（胜负退皆算）就留下 4 个月**破口**——该地跳过驻防生长，每月 -6（下限 30）。
  新行动**断其财路**（1 行动点＋`20+驻防×0.15` 万）让目标 3 个月不长驻防、每月 -10，与破口叠加为 -14。
  新行动**重金策反**（1 行动点＋40 万，对失序势力 28 万）成功则驻防 -25、姿态转「人心浮动」，失败则声望 -3 且惹火上身。
  **打输不再是白打，是买下了对面的失血期。**
- **豪强失序**：AI 势力地盘数 ≥6 即进入失序（`disorder = n-5`）。驻防上限改为 `90+n×30-disorder×22`，
  九块地的一家从 360 压到 272；每月按失序点数掷骰，抢来的地会「街面生乱」掉 15~25 驻防，
  驻防已低于 50 的还可能直接卷账本走人变回散户。老巢不参与——人心不会说散就散。
- **终局决战**：只剩一家 AI 且玩家地盘 ≥8 并不少于对方时，触发**雾港最后一张桌**——总攻（一场特殊三段式血拼，
  破口／封锁／策反／民心／临阵砸钱都折成准备度）、和局收编（义字流派或声望≥70，按对方地盘数付钱）或再等半年。
  反向地，某家吃到 8 块地且已过第 30 月，会**兵临老街**：前一个月必有苏曼青的顶级警讯，
  次月守城三档结算——守住则对方全境驻防×0.6、最远一块当场反水；惨胜则保住祖堂但折掉一半家底和最外沿一块地；被打崩即败局。
- **加时有代价**：第 66 月起每 6 个月收入系数累乘 ×0.95、外部压力地板 +8；
  **第 96 月强制结算**，按当时地盘数给出「半壁雾港」（≥10）／「割据一方」（6~9）／「退场」（≤5）。雾港名录只收一统。

## 启动

在本目录执行：

```bash
python3 -m http.server 8777
```

然后访问 `http://127.0.0.1:8777/`。

## 检查与封装

```bash
node --check app.js
node tests/structure.test.mjs
node tests/balance.test.mjs
python3 build_single.py
```

`balance.test.mjs` 用固定种子的四种玩家画像（莽夫／稳健／稳健·围困／躺平）各跑 24 局完整战役，锁住难度曲线。
当前基准（14块地图，2026-08 破局机制之后）：稳健打法标准难度中位约 53 个月通关、六成胜率——主战役打满，常进加时；
会用围困工具的稳健派中位约 49 个月，仗打得更多、丢地也更多；莽夫速通约 18 个月；死战通关率约五成；躺平必亡。
**所有画像的所有局都必须在第 96 月前抵达结局**，且「玩家与各存活 AI 的地盘数连续 24 个月完全不变」会被僵局哨兵判为失败。
AI 掷骰的 rng 必须从 advanceMonth 一路传到底：漏一处 Math.random，固定种子就锁不住曲线（实测稳健档会在 6~19 通关之间摇摆）。AI 从玩家手里夺地后有 3 个月缓手冷却，防止战略连击造成不可翻盘的雪崩。
注意：敌方地盘的开局防守姿态是固定的（易主后才随机重掷），否则固定种子会失去意义。
AI 战略扩张对玩家地盘用小标度攻击力（与"敌对反扑"同级），对散户与同行用大标度——
两套标度不能混用，否则玩家的新占地会陷入永久拉锯（实测 90 个月 74 胜仍困在 3 块地）。
改动战斗或经济数值后它会先叫。
行动卡的文案有预算：效果标签 ≤13 字、锁定文案 ≤14 字、图标单字，`structure.test.mjs` 会拦。
地图上「围困中」用金色（你的机会）、「失序N」用红色（对方的裂缝），两枚标记与「未稳」共用一套尺寸。

`SIEGE_SCALE`（守城战攻方缩放，当前 1.5）是「兵临老街」难度的唯一旋钮；破口失血量(6)、失序上限折扣(22)、
总攻准备度加成(8%) 是破局机制的三个旋钮——按这个顺序调，一次只动一个。
守城战的攻击力必须走小标度：用 Σ驻防 的大标度算，八块地的一家能凑出 700 战力，对玩家的 200 天花板不是决战是处刑（实测 24/24 全灭）。
