# 模拟社团老大 · 美术改版规范（旧账簿）

2026-10-07 定稿前版本。方向样张见 `docs/美术改版-三个方向.html` 里的 B。

## 一、基本想法

整个游戏是摊在一张深色木桌上的东西：父亲留下的账本、夹在本子边上的照片、压在桌上的信和便条。

- **木桌**：最底层。顶栏、侧栏、主菜单背景都在桌面上。
- **账页**：主要内容区。议事堂、地盘、血拼这些页面都写在账页上。
- **照片**：人物立绘一律做成白边相纸，可以有胶带、轻微歪斜。
- **信笺、便条**：事件弹窗、剧情、提示。
- **印章**：主要按钮、确认动作、“已办”状态。

要去掉的：玻璃毛玻璃效果、大圆角卡片、青绿渐变、英文小标题（MONTHLY COUNCIL、BATTLE PLAN、CHRONICLE、HARBOR / 001、FOG HARBOR / 18 DISTRICTS）、发光效果。

## 三、字体

不打包字体，全用 Mac 和 iPhone 自带的，Windows 有对应兜底。

- **宋体**（标题、人名、数字、按钮、地名）：`"Songti SC","STSong","Noto Serif CJK SC","SimSun",serif`
- **苹方**（说明文字、长段正文、表单）：`"PingFang SC","Microsoft YaHei",sans-serif`
- **楷体**（人物引语、军师批注、照片上的手写名字）：`"Kaiti SC","STKaiti","KaiTi",serif`

字号：页面标题 28/24（手机），区块标题 18，行标题 15，正文 13–14，注释 12。数字一律宋体加粗，等宽对齐（`font-variant-numeric: tabular-nums`）。

## 四、形状和质感

- 圆角最多 3px，大部分直角。
- 阴影只给“放在桌上的东西”（账页、照片、便条），`0 10px 24px rgba(0,0,0,.45)`。账页里面不用阴影，靠格线分隔。
- 纸面纹理：一张内联的 SVG 噪点（feTurbulence，几百字节），叠在 `--paper` 上，透明度很低。
- 账页左边一条朱红竖线（账本的装订线），手机上去掉。
- 照片统一加 `sepia(.2) contrast(1.05)`，让 AI 立绘看起来像同一批洗出来的照片。敌方人物再加一点灰。

## 五、组件

**按钮四种**
1. 主按钮：朱红实心印章，米色宋体字。用于开战、结束本月、确认。
2. 印章按钮：朱红空心框，略歪 -1.5°。用于行动“安排”、招募“请来”。
3. 文字按钮：墨色宋体加下划线。用于次要操作、筛选。
4. 禁用：褪成浅灰褐的空框，字写原因（“眼下无伤”“行动点用完”）。

做过的行动盖一个实心章“已安排”。

**合计栏**：替代现在的四格数字卡（metrics）。一行横排数字，上下双线，像账本的合计行。

**账页行**：替代大部分卡片。左边一个朱红大字（行动的“众”“练”这类图标字），中间标题和一行说明，右边效果，最右按钮。行之间一条格线。

**照片卡**：白边相纸，底下楷体手写名字，可选胶带。用于头目、招募人物、侧栏玩家。

**小签**（stat-chips、效果标签）：细墨线小方框，宋体数字。涨的写墨绿，掉的写朱红。

**进度条**（士气、忠诚等）：2px 细线，底色 `--rule`，填色墨或朱。

**便笺弹窗**：一张略泛黄的信纸压在暗下来的桌面上，左上贴人物照片。标题宋体，正文苹方，人物台词楷体。选项是账页行，右边一个“定”字章。

**提示条**（toast）：桌角一张小纸条。

## 六、各页面怎么改

**外壳**
- 顶栏在桌面上：左边“和”字印章加和联胜、章节；右边月份、行动点、现金、能战人手。行动点画成三个小圆印，用了的变空心。“存”“重”收成两个小文字按钮。
- 页面切换做成账本右边的书签页签（竖排字），当前页签朱红。手机上改成底部一排页签。
- “结束本月”改成“合账 · 结束本月”，墨色实心，固定在账页右下；手机上浮在底部页签条上方。
- 桌面左侧栏：玩家照片、势力根基（小账页卡）、本月收支（收入墨色，支出朱红）。手机上侧栏收成顶栏下一行“士气 62 · 声望 18 · 人心 55 · 压力 8 · 净收 +4.5万”，点开看详情。

**议事堂**
- 顶部：标题“沈川，这个月和联胜做什么？”，一句说明，合计栏，世道标签。
- 14 个行动按三组排成账页行：
  - 堂内事：众、练、账、茶、药、静
  - 守地盘：守、镇
  - 对外手段：眼、和、间、应、封、策
- 产业的三个图标字（茶/市/运）用在地盘页的产业上，同样是朱红大字。
- 桌面宽屏两栏排，一屏放下；手机单栏。
- 三名旧部放到页脚，一排小照片加名字、职位、忠诚。

**招募**
- 有名有姓的三个人做照片卡，没满足条件的照片蒙一层灰，写“还差什么”。
- 本月招募市场改成账页行：名字、类型、五维、开价、“请来”章。

**地盘**（改动最大）
- 地图做主角，宽屏占账页左边约三分之二，画成手绘港区图：纸底，海是淡靛色水彩，海岸线墨线，通路是虚墨线，地段是印泥圆点（自家地段是方形朱印），中环画一个“终”字章。
- 点地段，右边三分之一出一张详情便条：归属、驻防、稳定、地租、产业、可以做的操作。手机上详情从底部抽出。
- 区域筛选和“我的生意 / 进攻前线”改成地图上方一排文字按钮。
- 现在的 36 张卡片墙收进“列表”视图，用页面顶上的“地图 / 列表”切换；列表是账页行：区、地段、归属、驻防、地租、等级、操作。

**血拼**
- 标题下合计栏（能战人手、士气、整训、情报）。
- 左边可攻目标做成紧凑行：地名、归属、驻防或“不明”、敌方姿态，选中那行左边盖朱红竖条。
- 右边一张“出战令”：战术四选一（选中的画朱圈），头目用小照片勾选（最多三人），人手滑杆（墨线加朱色滑块），战前评估写成苏曼青的楷体朱批，底下主按钮“发令 · 开战尖沙咀”。
- 三段式战斗过程：战报一段一段展开，形势条做成朱和墨两色的拔河线。

**名册**
- 自家头目：照片卡一排，下面每人一行档案：五维、忠诚、怨气、功劳、伤情。
- 雾港其他人物：同样排法，照片灰一点，标所属势力色。

**江湖录**
- 流水账：左列“第N月”，右列记事。好事墨色，坏事朱红。
- 顶上合计栏。存档两个按钮放最下面。

**主菜单**：账本封面。深色布面，书名宋体烫金色（#c9a96a），右下朱印“雾港 和联胜”，玩家照片斜夹在封面上。按钮是从本子里伸出来的书签：继续、新开一局、雾港名录。

**建角**：账本扉页，像立契。名字写在一条横线上；三组选择（父亲的话、难度、年景）做成可圈选的条目，选中画朱圈。父亲的照片和那句话放左边，话用楷体。

**序章、剧情**：信纸，正文宋体 16px，人物照片贴角上，进度是页脚的页码“一 / 五”。

**结局**：账本最后一页“结账”，大号朱印压在结论上。

**排行榜**：名录表格，账页格线，名次用宋体大字。

## 七、不动的东西

- 数值、玩法、存档格式、剧情文案都不改。只改两类字：去掉英文小标题，几个按钮名换成账本说法（“合账 · 结束本月”“发令 · 开战”）。
- 不新画立绘，不新增图片文件。纹理全部用 CSS 和内联 SVG。
- 元素 id 不改，测试和存档逻辑不受影响。

## 八、施工流程

0. **备份**：当前状态打一个 git 标签 `before-ledger-ui`，方便回退。
1. **底子**：重写 style.css 的颜色、字体、纸面、按钮、账页行、照片卡、印章、合计栏这些基础件。改 `FACTIONS` 颜色。
2. **外壳和议事堂**：顶栏、书签页签、侧栏、结束本月、手机底栏；议事堂按三组重排。**做完这步停下来发截图给你看**，手感对了再往下铺。
3. **招募、名册、江湖录**：主要是换样式，模板小改。
4. **地盘页**：地图重画、详情便条、地图/列表切换。这步要动 `renderMap` 的交互。
5. **血拼**：计划页、三段式战斗、战报。
6. **其余画面**：弹窗、序章、建角、主菜单、结局、排行榜、提示条。
7. **手机检查**：390 宽每页截图过一遍，修溢出和遮挡。
8. **收尾**：跑 `node --check` 和三个测试，`build_single.py` 重出单文件版，git 提交。每一步的截图都发你。
