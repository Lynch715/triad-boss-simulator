# 战斗改版提案：头目卡牌对战

状态：已施工（2026-10-07）。参考《三国群英录》《水浒群星录》的武将＋兵力＋技能自动战斗，但保留社团老大现在“每段听头目出主意”的味道。

## 一、现在的血拼哪里不好玩

- 一场仗就是三段文字，每段从两三个提议里点一个，结果是一行字加一个势头数。头目是谁、带了多少人，在战斗里几乎看不出来。
- 头目只有五维和一句特性，没有招式。赵魁和程野上场，打法上没区别，只是数大数小。
- 小弟是一个总数，分不到人头上，谁的人先打光、谁扛住了，没有画面也没有选择。

## 二、新打法一句话

我方最多三名头目各带一队小弟，对上敌方守将；小弟就是血量。每段自动打两回合，头目按技能出手；段与段之间，玩家从手里的“号令牌”里出一张，决定下一段怎么打。

## 三、头目卡

每张卡：照片、名字、类型、五维、技能、小弟数。五维在战斗里的用处：

| 属性 | 战斗里管什么 |
|---|---|
| 武 | 出手伤害 |
| 统 | 能带多少小弟（上限 = 10 + 统 ÷ 4），受到的伤害减免 |
| 谋 | 主动技能发动率、识破对方的计 |
| 魅 | 劝降成功率、自己小弟不容易溃散 |
| 经 | 战后救回伤员的比例、战利品 |

小弟分配：开战前把“参战人手”分给上阵头目，默认按统率自动分，玩家可以拖动调整。头目的小弟打光就算这一路败退，按现在的规则有概率负伤。战后伤亡照旧分进整补、养伤、阵亡三个池子，跟现在的人手系统接上，不另起一套。

## 四、技能

参考三国的分类，压成四种：

- **主动**：有发动率，出手时判定，比如“对一人 1.6 倍伤害”。
- **被动**：一直生效，比如“小弟低于三成时武 +10%”。
- **追击**：普攻后按几率再补一下。
- **压阵**：上场就对全队生效，比如“全队受到的伤害 −8%”。

有名有姓的人物每人两个专属技能，按人设写。举几个例子（文案只是示意）：

| 人物 | 技能 |
|---|---|
| 赵魁 | 「镇场」压阵：同排友军受到伤害 −10%（原名「压阵」，2026-10 改名）。「开路」主动 35%：对一人 1.6 倍。 |
| 苏曼青 | 「算账」压阵：开战前的胜算判断更准，全队谋 +10%。「断粮」主动 30%：敌方全体下一回合伤害 −20%。 |
| 程野 | 「喊话」主动 30%：劝走小弟最少的敌将手下一批人，战后有机会收编。 |
| 沈川 | 随开局那句话变：义字当头＝劝降更容易；人必须怕你＝首回合全队武 +15%；钱要永远先到＝开战前可花钱稳住士气。 |
| 韩彪（敌） | 「硬碰」主动：单挑我方武最高的头目。 |
| 方景曜（敌） | 「砸钱」：我方魅低的头目会被撬走一批小弟。 |
| 魏小楼（敌） | 「第二扇门」：小弟打光时带残部跑掉，不会被俘。 |
| 阿七 | 「跟着学」：每打过一场伤害 +1%，最多 +15%（2026-10 调整）。 |

普通头目按类型（猛将、统将、策士、探子、管事、说客、商枭等）从技能池里随机给一个，大约做 16 个。

## 五、号令牌

现在每段的“头目提议”改成手牌。每段开打前发 3 张，出 1 张：

- 牌从上阵头目身上来，比如赵魁带来「压上去」，程野带来「喊话劝降」，苏曼青带来「稳住阵脚」。
- 战术（强攻、稳打、奇袭、攻心）决定牌堆里哪类牌多。
- 对方姿态的克制关系照旧：查过情报才看得到哪张牌被克。
- 永远有一张「撤」，跟现在一样可以中途收兵。

## 六、敌方

- **守军**：地段的驻防值换算成敌方小弟总数，分给守将。
- **三家社团的核心地段**：派名将上阵，何万山、唐霁、方景曜、韩彪、顾长风、魏小楼。
- **其他地段**：用随机生成的无名头目。
- **散户地段**：用“地头蛇”卡，比较弱，适合开局练手。

## 七、界面（旧账簿风格）

- 账页上下两排照片卡：上面敌方，下面我方，卡下面一条小弟数的横格。
- 技能触发时在照片上盖一个小朱印写技能名。伤害用红墨数字飘出来。
- 右边一栏战报流水。
- 手牌在下方，出牌就是盖章。
- 自动播放，分一倍速、两倍速和直接看结果三档。手机上两排卡缩小，战报收起来。

## 八、跟现有系统怎么接

- **胜算显示**：开战前的胜算判断改成用新引擎快速模拟几十场，给出几成把握，比现在的估算公式准。
- **敌方之间打仗**：敌方互相吞并、反扑、围城仍用现在的抽象公式，不跑卡牌战斗，免得月结变慢。
- **旧存档**：旧存档里打到一半的血拼，载入时按旧规则直接结算完。
- **测试**：结构测试里有 40 多处直接调用旧的三段式，要重写。平衡测试的机器人要会出牌，然后重新校准通关月数。

## 九、施工流程（确认后再动）

1. **引擎**：战斗引擎单独写成纯逻辑，不碰界面，可以在 node 里带种子复现。先做普攻、小弟伤亡、四类技能、号令牌。
2. **技能数据**：写名将专属技能和普通技能池。跑模拟看每个技能的强度，太强太弱的调平。
3. **界面**：卡牌对阵、播放、出牌。**做完停下发截图给你看。**
4. **接入**：开战流程、战后结算、胜算判断、旧存档处理接进去。
5. **测试和平衡**：重写结构测试，平衡测试改用出牌机器人，重新校准难度。
6. **收尾**：打包单文件版，提交。

这是一次大改，旧的三段式会在新引擎通过平衡测试之后才删。

## 十、后续调整（2026-10）

- 人数整体放大十倍：开局 420 人，社团地盘一千出头，堂口两千八；每人能带（12＋统率÷2＋等级加成）×10 个小弟。
- 三家堂口（香港仔、湾仔、长沙湾）：驻防两倍半、本家头目全部守门、守方受伤 −15%；外围还剩 3 块以上时不开放进攻；拿下后本家其余地盘驻防 −30%。
- 头目等级 Lv1~10：打仗攒经验，升级加主属性和带兵上限；Lv5 普通头目学第二个技能，名将技能升「·贰」，Lv10 升「·叁」。对家头目每年涨一级。
- 何万山的码头加成只保留「老码头」技能，守方战力不再另乘 1.08。
- `CARD_ENEMY` 由 1.5 调到 1.6。规则细节见 README。
