# 模拟社团老大 · 雾港风云

## 十八区经营与争霸版（2026-10-07）

地图参考香港民政事务总署的[十八区划分](https://www.had.gov.hk/chs/18_districts/my_map.htm)，每区拆成两个经营地段，共36块地盘。港岛4区、九龙5区、新界9区；界面为方便浏览，将属于新界的离岛区单独筛选。城市轮廓、交通连接、产业适配和势力分布均为玩法示意，不是精确行政地图。人物与剧情保留架空雾港设定。

### 地图与进攻

- 开局据点为油麻地老街，可向尖沙咀、深水埗、九龙城扩张。
- 支持全部、港岛、九龙、新界、离岛筛选，并可筛选“我的生意”和“进攻前线”。
- 地图节点可点击或键盘操作，定位对应地段卡片；从卡片进入进攻计划或产业经营。
- 陆路、跨海连接共同决定邻接。除中环外，35处普通地段不依赖终局区域即可全部到达。
- 中环为最终区域，常规进攻需先取得其余35处地段。
- 血拼改为头目卡牌对战（见下节），保留战术克制、主政、伤员整补、外交、封锁与策反。

### 地盘经营

每处自家地段能开办一种产业，最高三级；开办或扩建消耗1行动点及现金，停业整备一个结算月，第二次月结起恢复营业。

| 产业 | 一级投资 | 一级基础营收/月 | 维护费/月 | 特色 |
|---|---:|---:|---:|---|
| 街坊生意 | 16万 | 6万 | 2万 | 茶楼、餐馆、修理铺方向 |
| 商贸经营 | 26万 | 10万 | 4万 | 商行、百货、旅店方向 |
| 仓储物流 | 22万 | 8万 | 3万 | 仓库、货运、维修方向 |

这些是三种产业方向，示例店铺不分别模拟。扩建费用为一级投资乘目标等级。产业随地盘易主。

- 本地适配产业营收乘1.25；稳定系数为0.5＋稳定/200。
- 物流地段与自家已营业的商贸地段相邻，营收再乘1.15。
- 稳健经营：营收正常，本地稳定每月+1。
- 扩大客流：营收+25%，本地稳定每月-3。
- 照顾街坊：营收-15%，本地稳定每月+4。
- 方针每月可改一次，不消耗行动点；日常营业自动结算。
- 地租与产业营收共同受到地盘等级、驻防期、主政、流派和年景影响；产业维护费单独计入总支出。卡片显示的是产业基础营收，月报显示最终收支。

### 战役与旧档

主战役120个月，最长180个月后强制结算。最终收编/总攻至少需要27处地段；敌方终局围城至少需要20处地段，并保留提前警讯。反攻对玩家的地盘数量和时间加成有上限，避免大地图无限放大敌军战力。

旧版14地盘存档按原ID保留现金、人员、地盘归属、战斗与剧情进度，地段改用新名称并补入22处区域；已灭势力不会因补地复活，已统一的结束存档保持统一。首次载入旧档时尝试在本地保存 `_before_18districts` 备份。迁移不是原版平衡的复刻；体验新地理和开局分布建议另开一局前自行保留旧档。

### 美术（2026-10-07 旧账簿改版）

界面改成“木桌上摊开的旧账本”：顶栏和侧栏在深色桌面上，内容写在账页上，人物做成旧照片，事件是信笺，主要按钮是朱红印章。字体只用系统自带的宋体、苹方、楷体，纹理全部是 CSS 和内联 SVG，没有新增图片。地盘页改成地图加详情便条，原来的卡片墙收进“列表”视图。规范见 `docs/美术改版规范-旧账簿.md`，改版前的版本在 git 标签 `before-ledger-ui`。

### 经营与战果反馈（2026-10-07）

- 产业选择显示按当前地段、主政与年景计算的月净收益预估；建设与扩建停业一个结算月；预估按驻防期结束后的常态收入算。
- 开业/扩建完成增加2声望，月报显示开业与首次回本喜讯；新增投入与净收益按地段保存。旧档未记录的历史投入不追算。
- 首次控制一个区的两个地段，获得8万贺礼和2民心；奖励记录随存档保存，失地重夺不重复发放。
- 战报增加实际入账、月净收变化、整补/养伤/阵亡人数；投资升级即时反馈收入增量。
- 精简主页面标题、开场说明与行动描述，保留费用、工期、风险等决策信息。
- 新增验证：`node tests/rewards.test.mjs`；原结构、十八区经营、96局战役测试通过。IAB验收桌面及390×844手机产业弹窗，单文件版加载无控制台错误。

### 头目卡牌对战（2026-10-07）

- 最多三名头目上阵，开战前把人手分给各人，每人能带（12＋统率÷2＋等级加成）×10 个小弟，带不动的人留在老街。小弟数就是这一路的血量。
- 头目分前后排：猛将、统将、龙头、新人默认站前排，其余站后排，出战令里可以切换。对面先打前排。
- 开局、僵持、决胜三段，每段自动打两回合，按武力高低轮流出手。段与段之间出一张号令牌，牌由上阵头目带来，效果管下一段。
- 技能分主动、追击、常驻、压阵四种，有名有姓的人物各两个专属技能，普通头目按类型从技能池里给一个，Lv5 再学一个。共 40 个技能，规格见 `docs/战斗改版提案-头目卡牌对战.md`。
- 开战时双方总战力之比与旧公式一致，过程不同。`CARD_ENEMY`、`CARD_SWING` 最初按旧版三段式的胜率曲线校准；2026-10 加入等级后 `CARD_ENEMY` 由 1.5 调到 1.6，抵掉我方头目升级带来的增强。
- 阵前劝下的人三成跟你走；被方景曜撬走的人不算阵亡，也不回来。进攻失利时守方门板按实际伤亡的 2.4 倍掉。
- 开战前的把握用同一套引擎空跑 40 场估算，种子固定。旧存档里打到一半的仗读档后按当时的强弱比摆开阵势接着打。

### 人数放大、帮派堂口、头目等级（2026-10）

- **人数×10**：开局 420 人、上限 600；散户地盘几百人，社团地盘一千出头，堂口两千八。所有人数相关的公式、文案、阈值同步放大，每人维护费与医药费按十分之一算，钱的节奏不变。旧存档读档时自动换算（含打到一半的仗），只换算一次。
- **堂口**：东潮会·香港仔、万盛堂·湾仔、长风社·长沙湾。驻防两倍半，上限两倍半、生长翻倍；本家能打的头目全部守门（最多三路）；守方受伤 −15%。本家外围还有 3 块以上时不开放进攻，地图上标「堂」和红色虚线圈。拿下堂口，本家其余地盘驻防 −30%。外围被拔光的孤城不再长人，每月散掉 4%。别家吃下的堂口只算普通地盘。旧档读入时把仍在原主手里的堂口驻防补到两倍半。
- **头目等级 Lv1~10**：出战 4 点、打赢 4 点、放倒的人每 50 人 1 点（最多 8）、放出技能每次 1 点（最多 4）；断后、主政、合练、剧情另有少量经验。升级所需 20＋12×等级。每升一级按类型给两项主属性各 +2（猛将武/统、军师谋/经、说客魅/谋……），带兵上限 +20。Lv5 普通头目学会第二个技能，名将技能升「·贰」，Lv10 升「·叁」：倍率、补人、劝人 +15%/阶，增减益偏移 ×1.4/×1.8，触发率 +15%/阶。对家头目每满一年涨一级。旧存档里隐藏的经验按「已长属性×10＋余数」×4 折算等级，不重复加属性。
- 技能调整：赵魁「压阵」改名「镇场」；何万山的码头加成只保留「老码头」技能，不再在守方战力里另乘 1.08；阿七「跟着学」改为每打过一场伤害 +1%，最多 +15%。
- 新增验证：`node tests/levels-hq.test.mjs`。
