# 模拟社团老大 · 雾港风云

架空港口城市背景的生涯策略游戏。你接过父亲沈振海留下的「和联胜」，从一条老街起步，招募头目、经营地盘、决定血拼战术、收编敌将，最终一统雾港。

**▶ [开始游戏](https://lynch715.github.io/triad-boss-simulator/)**

单文件网页游戏，打开即玩。存档保存在浏览器本地，无后端、无 CDN、不上传任何数据。

## 玩法

- 60 个月主战役，每月 3 个行动点
- 8 块城区、3 家敌对社团，中央港区为终局之战
- 头目五维：武力、统御、谋略、经营、魅力
- 14 名核心人物，各有独立立绘、专属特性与剧情线
- 义、威、利三种执掌倾向，通向不同结局

## 三段式血拼

每场血拼分**开局 / 僵持 / 决胜**三段，每段独立判定并累计「势」。三段打完势为正才算赢——所以劣势开局仍有机会翻盘，优势开局也可能阴沟翻船。

每段结束后由**你带去的头目**提出建议，带谁去直接决定你能打出什么牌：

| 头目 | 提议 | 效果 |
|---|---|---|
| 赵魁 | 「压上去，别给他们喘气」 | 势↑↑，伤亡↑↑ |
| 苏曼青 | 「他们左翼是空的」 | 势↑，伤亡↓ |
| 魏小楼 | 「后门我一直留着」 | 势↑，当场揭穿真实驻防 |
| 程野 | 「让我去喊一嗓子」 | 胜则收编敌兵，但这块地不服你 |
| 叶蓉 | 「退路和粮草我安排好了」 | 伤亡↓↓，撤退不掉士气 |
| 阿七 | 「我来断后」 | 伤亡↓，但他自己更容易挂彩 |
| 赵魁／韩彪／谢九 | 「那个人交给我」 | 单挑：胜则压制对手，败则自己被抬下去 |

第二段起可以**鸣金收兵**——保住剩下的人，只付已经打完那几段的血。什么时候止损，是这套系统里最实在的决策。

战斗进度会存进存档：打到一半刷新页面，回来还在同一段，人手和局势分毫不差。

## 本地运行

```bash
git clone https://github.com/Lynch715/triad-boss-simulator.git
cd triad-boss-simulator
python3 -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。
